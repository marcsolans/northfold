# {{project_name}}

Proyecto de Messer. Todo es código: `workforce/` contiene los agentes y flujos, `interfaces/` las pantallas y
`knowledge.yaml` / `triggers.yaml` sus enlaces y disparadores.

- Ejecutar en local: `messer start`
- Evals: `messer evals run --local` (o en Messer: `messer evals run`)
- Publicar: `messer push` y después `messer deploy`
