---
title: "Windsurf"
description: "Step-by-step instructions to integrate Messer with Windsurf through MCP."
---

> ## Step 1: Open the Windsurf interface
1. Launch the Windsurf app on your system.
2. Log in with your account if required.

> ## Step 2: Access MCP settings
1. In the top menu, click **Settings** (<Icon icon="gear" size="14" />  on the top-right) -> **Windsurf Setting**s.
2. Navigate to the **Cascade** section → **MCP Servers**.
3. Click the **Open MCP Marketplace** link.


> ## Step 3: Add Messer as a new MCP server
1. In the **Installed MCPs** list, click the **Settings** button (<Icon icon="gear" size="14" /> positioned to the right of the title). 
2. The file `mcp_config.json` will open.
3. Add the Messer MCP URL (`https://api.messer.local/mcp`). For example, you can set the server name `"messer-mcp"`:
    ```json title=mcp_config.json
    {
        "mcpServers": {
            "messer-mcp": {
                "serverUrl": "https://api.messer.local/mcp",
                // Use this to authenticate with a Messer API Key instead of OAuth
                // "headers": {
                //    "Authorization": "<MESSER_API_KEY>"
                // }
            }
        }
    }
    ```
4. Save the configuration.

### Option 1: Connect via OAuth
5. A browser window will open for authentication.
    <Note>
    If the pop-up does not appear, you can manually click the **Connect** button next to Messer MCP in the **MCP Marketplace**.
    </Note>
6. Log in using your preferred OAuth method: GitHub, Google, Microsoft, or Messer OAuth.
    <Warning>
    Make sure to log in with your active Messer account — the account registered on the [Messer Platform](https://app.messer.local). Using a different account may prevent access to Messer tools.
    </Warning>
7. Accept the OAuth permissions.
8. Return to Windsurf — Messer should now appear in green, with available tools listed inside.

### Option 2: Connect using a Messer Api Key
5. If you added a `"Authorization"` with `"MESSER_API_KEY"` in `mcp_config.json`, Windsurf will automatically use it — no browser login is needed.  
6. Check the **Installed MCPs** list — Messer should appear in green, with its tools ready to use.  

> ## Step 4: Start using Messer in Windsurf
1. Open the **Toggle Cascade Side Bar** (<Icon icon="sidebar" size="14" />  on top-right).
2. Start a chat.
3. You can now use **Messer tools** in your conversation. Windsurf will leverage the MCP integration automatically.
